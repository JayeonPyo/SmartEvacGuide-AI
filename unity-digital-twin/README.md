# Unity Digital Twin

건물의 입체 구조를 가상 공간에 재현하고, 현재 재난 상황과 대피 경로를 **1인칭 시점**으로 안내하는 디지털 트윈 클라이언트입니다. oneM2M(tinyIoT) 서버를 HTTP 폴링해 현실 공간의 상태를 동기화합니다.

조감도 기반 안내는 실제 재난 상황에서 건물의 입체 구조 때문에 효과가 떨어질 수 있다는 문제의식에서 출발했으며, 위험 요소를 시각·청각적으로 함께 전달해 회피를 돕습니다.
